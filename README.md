# Datenbankmanagment_Project

> **Schulprojekt:** Datenbankentwicklung im 2. Semester

Ein Teamproject zur praktischen Anwendung von Datenbankentwicklungsmethoden — von der Anforderungsanalyse bis zur physischen Implementierung.

---

## Assignments

| # | Titel | Fokus | Status |
|---|-------|-------|--------|
| 1 | **Personas, Stakeholder Interviews, Reflection** | Anforderungsanalyse, Personas, Interview-Guides | ✅ Fertig |
| 2 | **Conceptual Data Modeling** | UML-Konzeptmodell, Daten-Dictionary, Validierung | ⏳ Geplant |
| 3 | **Logical Data Modeling** | Relationales Modell, Normalisierung | ⏳ Geplant |
| 4 | **Physical Database Design & Implementation** | SQL, Implementierung, Testen | ⏳ Geplant |

---
