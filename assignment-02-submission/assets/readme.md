# Assets Overview

This directory contains the supporting materials for Assignment 02: Conceptual Data Modeling.

## Folder Structure

- **`diagrams/`**
  - `conceptual-model-initial.puml` - PlantUML source code for the initial conceptual data model.
  - `conceptual-model-initial.svg` - Rendered SVG diagram for the initial conceptual data model.
  - `conceptual-model-final.puml` - PlantUML source code for the final revised conceptual data model.
  - `conceptual-model-final.svg` - Rendered SVG diagram for the final revised conceptual data model.
  - `T1_T2_Pathways.puml` - PlantUML source code for transaction T1 and T2 entity traversal pathways.
  - `T1_T2_Pathways.svg` - Rendered SVG diagram for transaction T1 and T2 pathways.
  - `T3_T4_Pathways.puml` - PlantUML source code for transaction T3 and T4 entity traversal pathways.
  - `T3_T4_Pathways.svg` - Rendered SVG diagram for transaction T3 and T4 pathways.
  - `T5_T6_Pathways.puml` - PlantUML source code for transaction T5 and T6 entity traversal pathways.
  - `T5_T6_Pathways.svg` - Rendered SVG diagram for transaction T5 and T6 pathways.
  - `T7_T8_Pathways.puml` - PlantUML source code for transaction T7 and T8 entity traversal pathways.
  - `T7_T8_Pathways.svg` - Rendered SVG diagram for transaction T7 and T8 pathways.
